# Rainmaker

Nature soundscapes for calm, focus and sleep, synthesized live in your browser. There are no recordings and no loops: rain, thunder, wind, ocean, a stream, fire, birds, frogs, crickets and dripping trees are each generated from a physical model, so a night of rain never repeats.

**Open it:** https://mijaelb.github.io/rainmaker-app/

**On an iPhone:** open the link in Safari, tap Share, then *Add to Home Screen*. It then opens full screen like an app and also works offline. On iOS 17 and later it is built to keep playing when the screen locks.

It also has slow-breathing guidance and short calm practices: attention training, leaves on a stream, muscle release, a bedtime to-do list and a sleep shuffle, each with a 0–10 check-in. These are self-help practices, not treatment.

This repository holds only the built website.
